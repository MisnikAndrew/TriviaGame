# 🧠 Борьба умов

Игра-викторина «один на один» в духе QuizDuel / «Борьба умов». Сервер на Go
(только стандартная библиотека, без внешних зависимостей), клиент — обычная
веб-страница, поэтому играть можно с телефона, планшета или другого ноутбука.

## Запуск

```bash
cd TriviaGame
go run .
```

В консоли появятся адреса:

```
🧠 Борьба умов запущена — 18 категорий, 951 вопросов

  На этом компьютере:  http://localhost:8080
  С других устройств:  http://192.168.1.4:8080
```

Откройте на другом устройстве адрес из строки «С других устройств» — устройства
должны быть в **одной Wi-Fi/LAN-сети** с ноутбуком.

> **macOS:** при первом запуске система спросит «Разрешить входящие подключения?» —
> нажмите **Разрешить**, иначе другие устройства не смогут подключиться.
> Если не спросила, проверьте *Настройки → Сеть → Брандмауэр*.
>
> Если в списке несколько адресов, нужен тот, что из вашей домашней сети
> (обычно `192.168.x.x`); `10.x.x.x` часто принадлежит VPN.

Готовый бинарник: `go build -o triviagame . && ./triviagame`.

### Параметры

| флаг | по умолчанию | что делает |
|---|---|---|
| `-addr` | `:8080` | адрес/порт (`127.0.0.1:8080` — только этот компьютер) |
| `-rounds` | `6` | раундов в матче |
| `-questions` | `3` | вопросов в раунде |
| `-time` | `15` | секунд на ответ |
| `-data` | вшитая база | папка с `*.json` вопросами — можно править без пересборки |
| `-public-url` | — | адрес, по которому игра открывается из интернета (`https://quiz.example.com`): подставляется в ссылки-приглашения |
| `-trust-proxy` | выкл. | брать адрес игрока из заголовков туннеля/прокси — только вместе с `-addr 127.0.0.1:8080` |
| `-tls-cert`, `-tls-key` | — | сертификат и ключ: сервер отвечает по HTTPS |
| `-max-players` | `1000` | сколько игроков пускать одновременно (`0` — без ограничения) |
| `-max-per-ip` | `30` | сколько открытых соединений разрешено с одного адреса (`0` — без ограничения) |
| `-skip-src` | — | не загружать вопросы из источников (`chgk`, `opentdb`) — см. раздел про интернет |

## Как играть

- **⚡ Быстрая игра** — случайный соперник: первый, кто нажал, ждёт второго.
- **👥 Играть с другом** — создаёте комнату и отправляете другу ссылку вида
  `http://192.168.1.4:8080/?room=AB3K` (или он вводит код комнаты вручную).
- **🤖 Против бота** — потренироваться в одиночку (соперник отвечает верно в 55–80 % случаев).

Правила, как в QuizDuel:

1. В матче 6 раундов по 3 вопроса на одну тему.
2. Тему раунда выбирает то один игрок, то другой — нажатием на сектор «колеса» из пяти случайных
   тем (у каждого сектора свой цвет и название; в матче темы не повторяются). Соперник видит то же колесо.
3. Оба отвечают на вопрос одновременно, у каждого 4 варианта и 15 секунд.
4. Верный ответ даёт **50–100 очков — чем быстрее, тем больше**. Неверный или отсутствующий — 0.
5. В **последнем раунде очки ×2**.
6. После матча — реванш (выбирающий категорию первым меняется) или выход в меню.

Если соединение пропало (например, телефон заснул), игра ждёт возвращения
25 секунд: за это время игрок может переподключиться и продолжить — страница
восстанавливает состояние сама. Потом победа засчитывается сопернику. Кнопка
«Сдаться и выйти» требует повторного нажатия, чтобы случайно не слить матч.

## База вопросов

18 тем, 951 вопрос (в основном средней сложности; в небольших темах
присутствуют и немного более лёгкие или более трудные): история, география, наука, природа и
животные, литература, кино и ТВ, музыка, спорт, технологии, еда и напитки,
космос, искусство, игры (видео- и настольные), мифология, комиксы и аниме,
транспорт, знаменитости, «Что? Где? Когда?».

329 вопросов написаны для проекта, 571 — **отобранный и переведённый на
русский** материал [Open Trivia DB](https://opentdb.com) (в файлах помечены
`"src": "opentdb"`), ещё 51 — вопросы ЧГК (см. ниже). Перевод делался небольшими партиями с отбором: средняя
сложность, 4 варианта ответа, без вопросов про английские слова и устаревших
фактов, сомнительные формулировки и неудачные неверные варианты заменены.
Переводы проверялись вручную, но не по первоисточникам — если заметите ошибку,
правьте файл в `data/`.

Тема «Что? Где? Когда?» (`data/18_chgk.json`, `"src": "chgk"`) — вопросы турниров
ЧГК из базы [gotquestions.online](https://gotquestions.online): условия и ответы
взяты у авторов, а три неверных варианта к каждому придуманы для проекта так,
чтобы правильный ответ не выделялся среди них. Вопросов «Своей игры» в базе нет:
подходящего открытого источника не нашлось.

> **Лицензия вопросов.** Записи с `"src": "opentdb"` распространяются под
> [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) (требование
> источника: указание авторства, пометка изменений, та же лицензия при
> распространении). Подробности — в [`data/NOTICE.md`](data/NOTICE.md). На
> исходный код программы это не распространяется.
>
> **Вопросы ЧГК — только для личного использования.** Их авторы выбрали
> лицензии CC BY-NC-ND / CC BY-NC-SA: изменённые версии нельзя распространять, а
> здесь они изменены (добавлены варианты ответа). Поэтому `data/18_chgk.json`
> нельзя публиковать, отправлять другим людям и использовать в коммерческих целях
> — если собираетесь делиться проектом, просто удалите этот файл.

Каждая тема — отдельный файл в `data/`:

```json
{
  "id": "history",
  "name": "История",
  "icon": "🏛️",
  "questions": [
    {"q": "В каком году началась Первая мировая война?",
     "correct": "1914",
     "wrong": ["1905", "1917", "1912"]}
  ]
}
```

Необязательное поле `"src"` у вопроса указывает на сторонний источник; у своих
вопросов его нет.

Правильный ответ пишется отдельно от трёх неверных, а порядок вариантов
перемешивается сервером для каждого вопроса — следить за позицией не нужно.

**Добавить вопросы** — допишите их в нужный файл. **Добавить тему** — положите
рядом новый `NN_имя.json` с уникальным `id`. База проверяется при старте
(ровно 3 неверных ответа, нет пустых и повторяющихся вариантов, нет
дубликатов вопросов, достаточно вопросов в теме), а понятная ошибка с указанием
файла и номера вопроса выводится сразу. По умолчанию база вшита в бинарник
(`go:embed`), поэтому после правок перезапустите `go run .` или запускайте с
`-data ./data`, чтобы читать файлы с диска.

## Устройство

```
main.go       флаги, запуск, вывод адресов в локальной сети
server.go     HTTP: SSE-поток состояния + POST-действия, раздача страницы
hub.go        игроки, быстрый подбор, приватные комнаты, реванш
match.go      матч как конечный автомат в одной горутине
view.go       JSON, который получает браузер
bot.go        бот
questions.go  загрузка и проверка базы
network.go    лимиты запросов, адрес игрока за туннелем, разбор -public-url
data/*.json   вопросы
web/          index.html, style.css, app.js (без сборки и фреймворков)
```

- **Сервер → браузер:** Server-Sent Events. Сервер каждый раз присылает *полный
  снимок* того, что нужно показать, поэтому переподключение и обновление
  страницы ничего не ломают.
- **Браузер → сервер:** обычные `POST /api/...`.
- **Матч** живёт в своей горутине и обрабатывает события по одному (ответ,
  выбор темы, таймер, отключение) — без блокировок внутри игровой логики.
- Правильный ответ уходит в браузер только в момент раскрытия, а время ответа
  меряется на сервере — подсмотреть или «накрутить» скорость из консоли нельзя.
- Идентификатор игрока хранится в `sessionStorage`: у каждой вкладки он свой,
  поэтому сыграть самому с собой можно, открыв две вкладки.

## Тесты

```bash
go test -race ./...
```

Покрывают базу вопросов, правила матча (очки, смена выбирающего, тайм-ауты,
реванш), дисконнект и сдачу, полную партию через настоящие HTTP/SSE-эндпоинты, а
также защиту для открытого сервера (лимиты запросов, адрес за прокси, переполнение).

## Запуск в глобальной сети

Игра — обычный HTTP-сервер, поэтому «глобальный» запуск сводится к тому, чтобы
порт ноутбука был достижим из интернета. Три способа — от самого простого.
Ноутбук при этом должен быть включён и не засыпать: вся игра живёт в его памяти.

### 1. Туннель — проще всего, не нужны ни роутер, ни «белый» IP

Туннель выдаёт публичный `https://…`-адрес и пересылает запросы на ваш компьютер.
Игра передаёт события через SSE (долгоживущее HTTP-соединение), поэтому туннель
должен его пропускать.

```bash
# терминал 1: игра слушает только этот компьютер, адреса игроков берутся из заголовков туннеля
go run . -addr 127.0.0.1:8080 -trust-proxy -skip-src chgk

# терминал 2: ngrok (brew install ngrok, затем один раз ngrok config add-authtoken …)
ngrok http 8080
```

ngrok напечатает адрес вида `https://что-то.ngrok-free.app`. **Откройте игру по нему**
(а не по `localhost`) — «Играть с другом» построит ссылку-приглашение от этого адреса.
Бесплатный план ngrok может показывать друзьям страницу-предупреждение с кнопкой
«Visit Site» — один раз нажать её нужно. Если у вас есть постоянный адрес (статичный
домен ngrok, свой домен), запускайте игру с `-public-url https://quiz.example.com`:
ссылки будут правильными, даже если вы сами открыли игру по `localhost`.

> ⚠️ **Быстрые туннели Cloudflare (`cloudflared tunnel --url …`, адреса
> `*.trycloudflare.com`) не подходят**: [Cloudflare не поддерживает через них
> SSE](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/), и игра
> будет «зависать». Именованный туннель Cloudflare (нужны аккаунт и свой домен) этого
> ограничения не имеет.

### 2. Проброс порта на роутере — нужен «белый» публичный IP

1. Закрепите за ноутбуком постоянный адрес в сети (в роутере: резервирование DHCP) —
   его показывает строка «С других устройств» при запуске, например `192.168.1.4`.
2. В роутере пробросьте TCP-порт `8080` на `192.168.1.4:8080` (раздел «Port Forwarding» / «Виртуальные серверы»).
3. macOS: при первом запуске разрешите входящие подключения (*Настройки → Сеть → Брандмауэр*).
4. Узнайте публичный IP: `curl https://ifconfig.me`. Сравните с «WAN IP» на странице
   роутера: если они **разные**, у провайдера общий адрес (CGNAT) — пробросить порт
   нельзя, используйте туннель.
5. Запустите `go run . -public-url http://ВАШ_IP:8080 -skip-src chgk` и отправьте
   друзьям `http://ВАШ_IP:8080`. Проверять надо **не из домашней Wi-Fi-сети**
   (например, с телефона по мобильному интернету): не все роутеры пускают «себя» по внешнему адресу.

Постоянный адрес вместо меняющегося IP даёт бесплатный DDNS (DuckDNS, No-IP) —
`-public-url http://имя.duckdns.org:8080`. Для HTTPS нужен сертификат на ваше доменное
имя (Let's Encrypt: `certbot`, `acme.sh`): `-tls-cert fullchain.pem -tls-key privkey.pem
-addr :8443`, порт `8443` пробросьте так же.

### 3. Облачный сервер (VPS)

```bash
GOOS=linux GOARCH=amd64 go build -o triviagame .   # на ноутбуке; скопируйте файл на сервер
./triviagame -addr 127.0.0.1:8080 -trust-proxy -public-url https://quiz.example.com -skip-src chgk
```

Перед игрой поставьте обратный прокси, который сам получит сертификат. Для Caddy
весь конфиг — это

```
quiz.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

(SSE-поток идёт без буферизации: сервер сам отправляет `X-Accel-Buffering: no`.)

### Что важно знать

- **Вопросы ЧГК нельзя показывать публично.** Их лицензия (CC BY-NC-ND/NC-SA)
  разрешает только личное использование, поэтому для открытого сервера запускайте с
  `-skip-src chgk` — тема «Что? Где? Когда?» тогда не загружается (при `-public-url`,
  `-trust-proxy` или HTTPS без этого флага сервер напомнит об этом при запуске).
  Подробности — в [`data/NOTICE.md`](data/NOTICE.md).
- **Авторизации нет**: играть может любой, кто знает адрес; приватная комната
  защищена только 4-символьным кодом.
- **Защита от перегрузки** включена всегда: не больше `-max-per-ip` открытых потоков и
  разумная частота запросов с одного адреса (адреса IPv6 считаются по сетям /64),
  перебор кодов комнат — после первых 10 попыток не чаще одной в 2 секунды, не больше `-max-players`
  игроков, медленные соединения обрываются. Это защита от случайной нагрузки, а не от
  целенаправленной атаки.
- **`-trust-proxy` включайте, только если игра доступна исключительно через
  туннель/прокси** (запуск с `-addr 127.0.0.1:…`): иначе любой сможет подделать
  заголовок со своим адресом и обойти лимиты.
- Адреса вашей домашней сети (`/api/info`) показываются только игрокам изнутри сети.
- Время ответа меряется на сервере, поэтому у игрока с медленным интернетом бонус за
  скорость чуть меньше: задержка в 0,2 с стоит менее одного очка из 50–100.
