# Источники вопросов

Вопросы без поля `"src"` написаны для этого проекта. Остальные взяты из
сторонних баз и распространяются на условиях, описанных ниже.

## Open Trivia DB (`"src": "opentdb"`)

Часть вопросов выбрана из [Open Trivia DB](https://opentdb.com) и **переведена на
русский язык** (с отбором: в основном средняя сложность, 4 варианта ответа,
проверка фактов, исключены вопросы, привязанные к английскому языку).
Тексты изменены: перевод, адаптация формулировок, замена неудачных неверных
вариантов, уточнение условий вопроса. Темы «Игры», «Мифология», «Комиксы и
аниме», «Транспорт» и «Знаменитости» целиком состоят из таких вопросов.

Исходные данные: © Open Trivia DB (PIXELTAIL GAMES LLC), лицензия
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).

Согласно условиям лицензии, переведённые вопросы (все записи с `"src": "opentdb"`)
распространяются на тех же условиях — **CC BY-SA 4.0**. Лицензия относится только
к данным вопросов, но не к исходному коду программы.

## Что? Где? Когда? (`"src": "chgk"`)

Тема «Что? Где? Когда?» состоит из вопросов турниров по «Что? Где? Когда?» из
открытой базы [gotquestions.online](https://gotquestions.online) (данные
[db.chgk.info](https://db.chgk.info)). Формулировки вопросов и правильные ответы
взяты у авторов; **неверные варианты придуманы для этого проекта**, а сами вопросы
местами сокращены и изменены, чтобы их можно было задать с выбором из четырёх
вариантов. Ошибки в таких изменениях — на совести проекта, а не авторов вопросов.

Авторские права на вопросы принадлежат их авторам. Условия базы по умолчанию —
[CC BY-NC-ND](https://creativecommons.org/licenses/by-nc-nd/4.0/deed.ru)
(указание авторства, только некоммерческое использование, без распространения
изменённых версий); у отдельных авторов — CC BY-NC-SA. Изменённые версии здесь
сделаны владельцем проекта **только для личного использования, без публикации**,
поэтому файл `data/18_chgk.json` **нельзя распространять** (выкладывать в
репозиторий, отправлять другим людям, использовать в коммерческих целях).
Если собираетесь делиться проектом, удалите этот файл — игра работает и без него
(должно остаться не меньше 8 тем).
